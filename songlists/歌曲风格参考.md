# 歌曲风格参考

生成时间：2026-07-27

用途：补全歌曲 metadata 时统一使用这些风格名称，避免同一种风格出现多种写法。

## 建议主分类

| 建议风格 | 适用范围 | 现有相关写法 |
|---|---|---|
| 流行 | 大多数华语、英文、粤语、日文流行歌曲 | 流行、粤语 |
| R&B | R&B、Soul、R&B / Soul、Urban Pop | R&B、R&B / Soul、Soul |
| 摇滚 | 摇滚、独立摇滚、英摇、乐队歌 | 摇滚 |
| 民谣 | 民谣、城市民谣、独立民谣 | 民谣 |
| 爵士 | Jazz、Swing、标准爵士、爵士改编 | 爵士 |
| Blues | Blues、蓝调 | Blues |
| 说唱 | Rap、Hip-hop、Trap、说唱歌 | 说唱 |
| 中国风 | 周杰伦式中国风、国风流行、古典融合流行 | 中国风、国风 |
| 古风 | 古风、国风古风、戏腔古风 | 古风 |
| 民歌 | 民歌、民族歌曲、传统民歌改编 | 民歌 |

## 补全规则

- 风格不要写语种或地区；语种已经有单独字段。
- `华语流行`、`欧美流行`、`粤语流行` 都统一写 `流行`。
- `R&B / Soul`、`Soul` 默认统一写 `R&B`，除非之后需要更细分。
- `爵士 / Blues` 尽量二选一：偏 Jazz standard 写 `爵士`，偏蓝调写 `Blues`。
- `国风` 如果是流行编曲加中国元素，写 `中国风`；如果是古风圈/戏腔/古韵曲风，写 `古风`。
- 如果不确定，先按最常见唱见版本填写，并在备注写“待歌手本人确认”。
